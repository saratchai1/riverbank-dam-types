# S6006 — ทดลองความไวของโครงสร้างและดิน

Issue [#13](https://github.com/saratchai1/riverbank-dam-types/issues/13) เพิ่มพื้นที่ทดลองที่เปลี่ยนตัวแปรครั้งละหนึ่งค่า แล้วคำนวณซ้ำด้วยสมการ R2 ที่แอปใช้อยู่ จุดประสงค์คือทำให้เห็นความสัมพันธ์ระหว่างค่าตั้งต้น ผลคำนวณ และเงื่อนไขของแบบจำลอง พร้อมเก็บชุดทดลองให้ตรวจย้อนหลังได้

ผลทดลองเป็นคำตอบภายใต้ค่าที่กำหนดและตัวแปรอื่นที่คงไว้ ไม่ได้ประเมินความน่าจะเป็นการวิบัติ จัดอันดับแบบที่ดีที่สุด หรือรับรองความปลอดภัยของโครงการ ช่วงค่าที่กรอกเป็นสมมติฐานของการทดลอง ไม่ใช่ช่วงแนะนำสำหรับออกแบบ

## ขั้นตอนใช้งาน

1. เลือกสถานี S6006 แล้วเปิดหน้า **10 ทดลองความไว**
2. เลือกว่าจะใช้ค่าปัจจุบันหรือทางเลือกที่บันทึกไว้เป็นฐาน การเลือกฐานสำหรับทดลองไม่คัดลอกข้อมูลกลับไปแก้โครงการ
3. เลือกตัวแปรหนึ่งรายการ กำหนดค่าต้นช่วง ค่าปลายช่วง และจำนวนจุดระหว่าง 3 ถึง 31 จุด แล้วสั่งคำนวณชุดทดลอง
4. อ่านกราฟของผลลัพธ์ที่เลือกพร้อมค่าฐาน และเปิดตารางเพื่อดูค่าป้อน สถานะ เหตุผล และผลต่างของแต่ละจุด
5. เลือกจุดที่ต้องการตรวจเพื่อเปิดสมการ การแทนค่า และเงื่อนไขของผลจุดนั้น หากจุดอยู่นอกขอบเขตแบบจำลอง ให้อ่านเหตุผลที่คำนวณไม่ได้
6. ส่งออก CSV สำหรับตรวจตัวเลข บันทึก JSON สำหรับเปิดชุดทดลองเดิม หรือสร้างรายงานแล้วพิมพ์เป็น PDF

การแก้ตัวเลือกทดลองหรือข้อมูลต้นทางไม่เปลี่ยนผลของชุดที่คำนวณไว้แล้ว ต้องสั่งคำนวณใหม่จึงได้ชุดผลใหม่ เมื่อเปิด JSON ชุดทดลอง ระบบเปิดสำเนาแบบอ่านอย่างเดียวและคำนวณผลกลับจากข้อมูลตั้งต้น ไม่ได้นำข้อมูลเข้าแทนโครงการที่กำลังทำงาน

## ตัวแปรที่ทดลองได้

ทะเบียนตัวแปรใน [`studies.js`](../projects/s6006/studies.js) รองรับตัวแปรต่อเนื่อง 13 รายการ ขอบเขตค่าทางตัวเลขของฟอร์มเป็นขอบเขตซอฟต์แวร์ ต้องตรวจเงื่อนไขร่วมของแต่ละจุดอีกครั้ง และไม่ใช่เกณฑ์แนะนำให้ออกแบบที่ปลายช่วงนั้น

| ตัวแปร | หน่วย | ผลที่เกี่ยวข้องโดยตรง |
| --- | --- | --- |
| อัตราลาด `geometry.slopeH` | H : 1V | รูปทรง ปริมาณทฤษฎี และกลไกดินที่เลือก |
| ความลึกแนวดิ่ง `soilInputs.verticalDepthM` | m | ความเค้นและส่วนกำลังดินที่ขึ้นกับความลึก |
| มุมเสียดทาน `soilInputs.frictionAngleDeg` | ° | กรณี effective stress |
| ความเชื่อมแน่น `soilInputs.effectiveCohesionKpa` | kPa | กรณี effective stress |
| กำลังไม่ระบายน้ำ `soilInputs.undrainedStrengthKpa` | kPa | กรณี undrained total stress |
| น้ำหนักจำเพาะ `soilInputs.unitWeightKnM3` | kN/m³ | กรณี `u = 0` และเงื่อนไขร่วมกับ γsat |
| น้ำหนักจำเพาะอิ่มตัว `soilInputs.saturatedUnitWeightKnM3` | kN/m³ | กรณีน้ำซึมขนานลาดหรือ undrained ตามโหมด |
| ความกว้างคาน `beamInputs.widthMm` | mm | กำลังคาน การจัดเหล็ก และน้ำหนักตัวอย่าง |
| ความสูงคาน `beamInputs.heightMm` | mm | กำลังคาน การจัดเหล็ก อัตราส่วนช่วง/ความลึก และน้ำหนักตัวอย่าง |

| ระยะปลอก `beamInputs.stirrupSpacingMm` | mm | กำลังเฉือนและเงื่อนไขรายละเอียดปลอก |
| กำลังคอนกรีต `beamInputs.fcKsc` | kgf/cm² | กำลังคานและเงื่อนไขวัสดุ คงการแปลง SI ของ R2 |
| ช่วงคานตัวอย่าง `beamInputs.spanM` | m | แรงจากน้ำหนักตัวอย่างและขอบเขตคานตื้น ไม่เปลี่ยน Mu/Vu ที่กรอก |

ตัวแปรดินที่ไม่ใช้ในโหมดปัจจุบันเลือกทดลองไม่ได้ ขนาดเหล็กดึงในชุดทดลองเป็นขนาดสมมติต่อเนื่อง ไม่ใช่รายการขนาดเหล็กที่มีจำหน่ายหรือข้อเสนอเลือกเหล็กจริง

## ฐาน จุดทดลอง และหลักฐานดิน/น้ำ

**ฐาน** คือสำเนาสถานี สถานการณ์ และข้อมูลอ้างอิง ณ เวลาสร้างชุดทดลอง ฐานมีผลคำนวณของตนเอง แม้ค่าฐานจะไม่อยู่ในช่วงที่เลือก หรือไม่ตรงกับจุดแบ่งช่วงใดก็ตาม

**จุดทดลอง** เกิดจากการเปลี่ยนตัวแปรที่เลือกเพียงรายการเดียวในสำเนาฐาน ค่าที่เหลือรวมทั้งแรง Mu/Vu และบริบทน้ำคงเดิม แต่ละจุดถูกตรวจด้วยเงื่อนไขของแบบจำลองอีกครั้ง จุดที่ไม่ถูกต้องยังอยู่ในทะเบียนผลพร้อมเหตุผล ไม่มีการปรับค่าตัวแปรอื่นหรือข้ามจุดนั้นโดยเงียบ ๆ

**หลักฐานดิน/น้ำ** ที่แนบเป็นหลักฐานของฐานเดิม การทดลองใช้ค่าใหม่ไม่ได้ยืนยันว่าค่านั้นเป็นค่าที่ได้จากหลุมเจาะ ผลทดสอบ หรือการตรวจวัด และไม่ได้ผูกหลักฐานใหม่ให้เอง ดูวิธีบันทึกและผูกหลักฐานใน [ข้อมูลดินและน้ำ](s6006-investigation-basis.md)

การเปรียบเทียบความเปลี่ยนแปลงของต้นทางต้องอ้างถึงสถานีและสถานการณ์ที่เลือกจริง การแก้สถานีอื่นไม่ทำให้ฐานของชุดนี้เปลี่ยน ขณะเดียวกัน การเปลี่ยนเอกสารอ้างอิงหรือบันทึกหลักฐานของฐานต้องมองเห็นได้ แม้ค่าทางตัวเลขยังเหมือนเดิม

## อ่านกราฟและตารางอย่างไร

| สิ่งที่แสดง | ความหมาย |
| --- | --- |
| ค่าฐาน | ผลที่คำนวณจากสำเนาฐานแยกจากจุดแบ่งช่วง |
| จุดบนกราฟ | ค่าที่คำนวณได้ ณ ตัวแปรค่านั้น ภายใต้ขอบเขตและเงื่อนไขที่ระบุ |
| ช่วงที่กราฟขาด | จุดไม่มีผลที่ใช้แสดงได้ ต้องอ่านสถานะและเหตุผล ไม่ใช่ผลเท่ากับศูนย์ |
| ค่าต่ำสุด/สูงสุด | ค่าต่ำสุด/สูงสุดเฉพาะจุดที่มีผลและคำนวณไว้ในชุดนี้ ไม่ใช่ค่าต่ำสุด/สูงสุดของช่วงต่อเนื่องหรือของทุกกลไกวิบัติ |
| ผลต่าง | ค่าจุดทดลองลบค่าฐาน เมื่อทั้งสองมีผลตัวเลขที่ใช้เทียบกันได้ |
| ผลต่างเป็นเปอร์เซ็นต์ | เทียบกับขนาดค่าฐานเมื่อฐานมีค่าตัวเลขและไม่เป็นศูนย์ ช่องที่คำนวณไม่ได้ยังคงไม่มีค่า |

แต่ละกราฟแสดงผลหนึ่งชนิดและหนึ่งหน่วยเพื่อไม่ทำให้กำลังคาน อัตราส่วนแรงต่อกำลัง และ FS ดูเป็นสเกลเดียวกัน เส้นที่เชื่อมจุดช่วยอ่านแนวโน้มของค่าที่สุ่มคำนวณ ไม่ยืนยันค่าระหว่างจุด และไม่มีการเชื่อมข้ามจุดที่ไม่มีผล

ตารางรายละเอียดและไฟล์ผลแสดงตัวเลขครบความละเอียดแบบ double ที่ระบบเก็บไว้เพื่อการตรวจทวน ความแม่นยำทางกายภาพยังขึ้นกับข้อมูลดิน วัสดุ และงานสำรวจต้นทาง เมื่อคำนวณซ้ำด้วย JavaScript runtime ต่างกัน ผลฟังก์ชันคณิตศาสตร์ เช่น [Math.atan2](https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-math.atan2) อาจต่างในหลักสุดท้ายจากการประมาณตัวเลข การตรวจซ้ำจึงตรวจค่าป้อน รุ่นสมการ และสถานะให้ตรง พร้อมใช้ค่าคลาดเคลื่อนเชิงตัวเลขเล็กน้อยกับผลคำนวณตามที่ชุดทดสอบกำหนด

ผลต่างบวกไม่แปลว่าดีขึ้นเสมอ เช่น การเพิ่มอัตราส่วนแรงต่อกำลังหมายถึงใช้กำลังมากขึ้น ส่วนผลต่างศูนย์อาจเกิดจากตัวแปรไม่อยู่ในสมการของผลนั้น ช่วงทดลองที่ต่างกันยังทำให้ขนาดการเปลี่ยนผลต่างกัน จึงไม่ควรใช้ความกว้างช่วงผลลัพธ์เพื่อจัดอันดับความสำคัญของตัวแปรโดยไม่พิจารณาช่วงที่เลือก

## เงื่อนไขโครงสร้างที่คงไว้

การทดลองเรียก [`calculateBeam`](../projects/s6006/engineering.js) ชุดเดิม ไม่แก้สมการหรือปิดเงื่อนไข R2

- กำลังดัดที่ใช้เทียบแรงคือ `usablePhiMnKnM` ซึ่งต้องผ่านสมมติฐานเหล็กดึงคราก ความเครียดดึงขั้นต่ำ และเหล็กดึงขั้นต่ำตามที่โมดูลตรวจ `phiMnKnM` เป็นค่าระหว่างคำนวณและไม่ใช้แทนกำลังที่ถูกระงับ
- กำลังเฉือนที่ใช้เทียบแรงคือ `usablePhiVnKn` เมื่อเหล็กปลอกขั้นต่ำหรือระยะปลอกไม่ครบ โมดูลใช้เพดาน `φVc/2` ตามนโยบาย investigation ที่อ้างอิง หาก `Vs` เกินขีดจำกัดหน้าตัด กำลังที่ใช้เทียบแรงไม่มีค่า
- จุดที่เหล็กหนึ่งชั้นไม่พอดี เหล็กบน/ล่างวางไม่ได้ หรืออัตราส่วนช่วงต่อความลึกอยู่นอกขอบเขตคานตื้น จะไม่มีผลหมวดคานของจุดนั้น ผลดินและรูปตัดที่ยังคำนวณได้เก็บแยกตามจริง การทดลองไม่แก้ความกว้าง ระยะหุ้ม หรือช่วงคานรายการอื่นให้ผ่านเอง
- Mu/Vu ที่ผู้ใช้ระบุเป็นแรงออกแบบที่คูณตัวคูณแล้ว การทดลองขนาดหน้าตัดหรือวัสดุไม่ได้วิเคราะห์ระบบใหม่เพื่อปรับแรงเหล่านี้ ตัวอย่างแรงจากน้ำหนักตัวคานรองรับง่ายแสดงแยกและไม่บวกเข้า Mu/Vu อัตโนมัติ
- Mu/Vu ที่ไม่ทราบคงเป็น `null` แม้กำลังหน้าตัดจะคำนวณได้ การกรอกศูนย์จริงคงเป็นศูนย์และยังต้องผ่านเงื่อนไขกำลังที่เกี่ยวข้อง

สูตรโครงสร้างเป็นสมการบางส่วนตามรูปแบบประวัติ ACI 318M-02 ที่ใช้ใน R2 ไม่ใช่การตรวจมาตรฐานปัจจุบันครบทุกข้อ และยังไม่ตรวจแรงบิด คานต่อเนื่อง จุดต่อ การยึดเหล็ก การโก่ง การแตกร้าว เสาเข็ม หรือปฏิสัมพันธ์ดิน–โครงสร้างเพิ่มขึ้น ดูการทบทวนเดิมใน [second-engineering-review.md](source-review/second-engineering-review.md)

## เงื่อนไขดินและน้ำที่คงไว้

การทดลองใช้ลาดอนันต์เนื้อเดียว ระนาบวิบัติขนานลาด และความลึกวัดแนวดิ่ง `z` จาก [`calculateSoil`](../projects/s6006/engineering.js) ชุดเดิม กรณีที่แสดงแยกตามรหัสเดิม:

| รหัสกรณี | สมมติฐานใน R2 |
| --- | --- |
| `dry` | Effective stress, `u = 0`, ใช้ γ ที่ระบุและ c′/φ′ |
| `parallel-seepage` | Effective stress, อิ่มตัวถึงผิวลาด น้ำซึมคงตัวขนานลาด ใช้ γsat และ `u = γw z cos²β` ไม่มีน้ำภายนอกค้ำยัน |
| `undrained` | Total stress, ใช้ Su และ γsat ไม่หักแรงดันน้ำซ้ำ |

ตัวแปรที่ไม่ใช้ในโหมดดินที่เลือกไม่ควรนำมาเป็นข้อสรุปว่ามีความไวต่ำต่อดินจริง น้ำสูง น้ำต่ำ และน้ำใต้ดินในบริบทสถานีไม่ได้ถูกแปลงเป็นแรงดันน้ำรูพรุน จึงไม่ใช่ตัวแปรของการทดลองแรงดันน้ำใน R2

`z` ไม่เท่ากับความสูงเขื่อน ความหนาตั้งฉากลาด ความลึกหลุมเจาะ หรือช่วงลึกตัวอย่างโดยอัตโนมัติ การเพิ่ม c′ ในสมการไม่ได้ตรวจรอยแยกแรงดึงหรือกลไกวิบัติอื่น ค่า FS ทั้งหมดเป็นผลของกลไกสมมติที่เลือก ไม่มีเกณฑ์ผ่านโครงการตั้งให้อัตโนมัติ และไม่มีการเพิ่ม global stability ดินหลายชั้น การไหลซึม น้ำลดฉับพลัน การกัดเซาะ หรือการทรุดตัว

### ดิน: จัดรูปด้วยอัตราลาด

ให้ `m = slopeH` เป็นส่วนราบของลาด `mH : 1V` และ `z` เป็นความลึกแนวดิ่ง โดย `tan β = 1/m` จะได้

```text
FSdry = c′(m + 1/m)/(γz) + m tan φ′

FSparallel = c′(m + 1/m)/(γsat z)
             + m(1 − γw/γsat)tan φ′

FSundrained = Su(m + 1/m)/(γsat z)
```

สำหรับ c′ = 5 kPa, φ′ = 45°, γ = γsat = 20 kN/m³, γw = 10 kN/m³ และ z = 2 m ผล effective stress เป็นดังตาราง ส่วนคอลัมน์ undrained ใช้ Su = 30 kPa แยกคนละโหมด

| m | FS dry | FS parallel seepage | FS undrained |
| ---: | ---: | ---: | ---: |
| 0.5 | 0.8125 | 0.5625 | 1.875 |
| 1 | 1.25 | 0.75 | 1.5 |
| 2 | 2.3125 | 1.3125 | 1.875 |
| 3 | 3.4166666666667 | 1.9166666666667 | 2.5 |

กรณี undrained ที่คง z แนวดิ่งมีพจน์ `m + 1/m` ซึ่งต่ำสุดที่ m = 1 ผลจึงไม่ได้เพิ่มตาม m ทุกช่วง การทดสอบนี้ป้องกันข้อความสรุปหรือการจัดเรียงที่สมมติว่า “ลาดราบขึ้นแล้ว FS ต้องสูงขึ้นเสมอ”

ความสัมพันธ์ที่ใช้ตรวจเพิ่มเติม:

- เมื่อ c′ = 0 ค่า FS effective ทั้งสองกรณีไม่ขึ้นกับ z
- เมื่อ c′ > 0 การเพิ่ม z เป็นสองเท่าทำให้เฉพาะส่วน c′ ลดเหลือครึ่งหนึ่ง ส่วนเสียดทานคงเดิม
- การคูณ Su ด้วยตัวคูณ k ทำให้ FS undrained เพิ่มเป็น k เท่า
- เมื่อ Su และ z คงเดิม การเพิ่ม γsat ทำให้ FS undrained ลดตามส่วนกลับของ γsat

### คาน: ระยะปลอกข้ามเงื่อนไขรายละเอียด

ค่าตรวจอิสระใช้ b = 300 mm, h = 550 mm, cover = 30 mm, ปลอก 2 ขาเส้นผ่านศูนย์กลาง 10 mm, เหล็กดึง 3 เส้นเส้นผ่านศูนย์กลาง 20 mm, f′c = 25 MPa, fy = 400 MPa และ fyv = 250 MPa ได้ d = 500 mm, Av = 50π mm² และ Vc = 125 kN

ก่อนพิจารณาเงื่อนไขรายละเอียด `Vs = 6250π/s` kN และ `φVn = 0.75(125 + 6250π/s)` kN สำหรับช่วงนี้ระยะปลอกสูงสุดที่โมดูลตรวจเท่ากับ 250 mm

| ระยะปลอก s (mm) | กำลังเฉือนที่ใช้เทียบแรง (kN) |
| ---: | ---: |
| 100 | 241.01215563702158 |
| 200 | 167.3810778185108 |
| 250 | 152.65486225480862 |
| 300 | 46.875 |
| 400 | 46.875 |

ที่ s = 300 และ 400 mm โมดูลจำกัดกำลังไว้ที่ `0.75 × 125 / 2 = 46.875` kN แม้กำลังเชิงสมการยังมากกว่านี้ กำลังดัดที่ใช้เทียบแรงคงเป็น 159.6138407026239 kN·m ทุกจุด จึงใช้ตรวจได้ทั้งการเปลี่ยนระดับของผลเฉือนและการไม่ทำให้ผลดัดเปลี่ยนโดยไม่มีเหตุ

### คาน: ค่าระหว่างคำนวณเพิ่ม แต่กำลังที่ใช้ตรวจถูกระงับ

อีกกรณีใช้ b = 350 mm, h = 500 mm, cover = 40 mm, ปลอกเส้นผ่านศูนย์กลาง 6 mm, เหล็กดึง 5 เส้น, f′c = 210 kgf/cm² และ fy = 4,000 kgf/cm² แล้วทดลองเส้นผ่านศูนย์กลางเหล็กดึง 25 ถึง 26 mm ตารางตรวจอิสระคำนวณด้วย Decimal ความละเอียด 60 หลักก่อนเทียบกับผล JavaScript

| เส้นผ่านศูนย์กลาง (mm) | ความเครียดดึง εt | φMn เชิงสมการ (kN·m) | กำลังดัดที่ใช้เทียบแรง |
| ---: | ---: | ---: | --- |
| 25 | 0.00416435766243642 | 290.451256589497 | คำนวณได้ภายใต้เงื่อนไข R2 |
| 25.5 | 0.00388225762665128 | 290.976666933418 | ไม่มีค่า: εt ต่ำกว่า 0.004 |
| 26 | 0.00361634985863496 | 291.454724896872 | ไม่มีค่า: εt ต่ำกว่า 0.004 |

จุดที่ถูกระงับยังมีสูตรและเหตุผลให้ตรวจ แต่กราฟกำลังที่ใช้เทียบแรงและอัตราส่วน Mu/กำลังต้องเว้นว่าง ทั้งที่ φMn เชิงสมการยังเพิ่ม การทดสอบนี้ตรวจว่าการทดลองไม่ใช้ค่าระหว่างคำนวณมาแทนเงื่อนไขกำลังที่ขาด

ขอบเขตการจัดเหล็กตรวจอีกกรณีที่ความสูง 140, 141 และ 142 mm โดยค่าต้นแบบมี cover 40 mm, ปลอก 6 mm และเหล็กบน/ล่าง 12 mm จะได้ความสูงขั้นต่ำ `2(40 + 6 + 12) + 25 = 141` mm จุด 140 mm ต้องไม่มีผลคาน ส่วนสองจุดถัดไปคำนวณได้ ค่าฐานสูง 500 mm ยังคงแสดงแยกจากช่วงทดลองนี้

ตัวอย่างทั้งหมดเป็นข้อมูลทดสอบซอฟต์แวร์ ไม่ใช่ค่าที่เสนอให้นำไปออกแบบเขื่อน S6006

## CSV, JSON และรายงาน

CSV เก็บข้อมูลระบุตัวตนของชุดทดลอง สถานี/สถานการณ์ต้นทาง ค่าป้อนครบทุกจุด ผลทั้ง 12 รายการ หน่วย สถานะ เหตุผล ผลต่างจากฐาน สมการ/การแทนค่า และเงื่อนไขที่คำนวณได้ของทุกจุด หลักฐานอ้างอิงแสดงเฉพาะแถวของฐาน ช่องที่ไม่มีผลยังคงว่างพร้อมเหตุผล ไม่เปลี่ยนเป็นศูนย์

JSON ชุดทดลองเก็บข้อมูลตั้งต้น ข้อกำหนดการทดลอง รุ่นสมการ และข้อมูลอ้างอิงของฐานเพื่อคำนวณกลับ ไม่ใช้ผลตัวเลขที่ฝังในไฟล์เป็นค่าที่เชื่อถือได้ การเปิดไฟล์นี้ไม่ใช่การเปิดไฟล์โครงการ และไม่เปลี่ยนรูปแบบโครงการ version 1/2/3

รายงานใช้สำเนาจากชุดผลที่บันทึกไว้ตอนคำนวณ พร้อมขอบเขตและค่าฐานครบ ตารางผลทั้ง 12 รายการของทุกจุด สมการ/การแทนค่าของจุดที่เลือก และหลักฐานของฐาน เมื่อแก้โครงการหรือชุดทดลองภายหลัง รายงานที่สร้างแล้วคงเดิม หากสำเนาหาย เสียหาย หรือไม่ตรงรุ่น ระบบระงับการพิมพ์และไม่สลับไปใช้ค่าเริ่มต้นแทน ค่า checksum ตรวจความสอดคล้องของไฟล์ ไม่ใช่ลายเซ็นรับรองผู้จัดทำหรือความแท้ของเอกสาร

ลิงก์รายงานอาศัยสำเนาในเบราว์เซอร์เครื่องที่สร้าง ใช้ PDF เมื่อต้องส่งรายงาน และใช้ JSON ชุดทดลองเมื่อต้องเปิดทดลองเดิมอีกเครื่อง โดยอ่านข้อจำกัดและข้อมูลต้นทางประกอบผลเสมอ
