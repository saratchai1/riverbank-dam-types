## เดโม่ที่เลือก

เปิด [`projects/s6006/index.html`](../../projects/s6006/index.html) ผ่าน static server ของ repository นี้ เดโม่มี 6 ส่วน: ภาพโครงการ, หน้าตัดปรับค่าได้, ตรวจปริมาณ, โครงสร้างและดิน, ที่มาวิศวกรรม, รีวิวชุดแบบ

ใช้ **S6006 บ้านแดนเมือง จ.หนองคาย** เพราะมีแบบ รายงานดิน/เสถียรภาพ และ Excel ถอดปริมาณที่เชื่อมระดับสถานีได้ เลือก BOQ ปัจจุบัน 1,000 ม. = 286 + 714 ม. แยกจากแบบ 1,195 ม. และบล็อกคำนวณเก่า 1,222 ม.

### ค่าที่อ่านจากเอกสาร

SD-02 (PDF หน้า 36 / แผ่น 35) ให้ระดับสัน +101, ตีน +88, ลาด 2.5H:1V, หินเรียงหนา 0.50 ม., ทรายหนาไม่น้อยกว่า 1.00 ม., ทางเท้า 2.95 ม., สันตีนหิน 1.50 ม., ลาดข้าง 1.5H:1V และความลึกตีนอย่างน้อย 2 ม. ทั้งหมดแสดงในระดับสมมติของแบบ

ภาพและปริมาณรูปตัดทฤษฎีใช้ความหนาตั้งฉากลาด และตีนหินสมมาตรฐานราบเพื่ออธิบายเรขาคณิต ปริมาณดิน/ทรายจริงต้องใช้ผิวดินเดิมทุกสถานี ไม่ใช้รูปปริซึมนี้แทน BOQ

SD-05 (PDF หน้า 39 / แผ่น 38) ให้คาน BF1 250×500 mm เหล็ก 2Ø12 บนและล่าง ปลอก Ø6 @200 mm เสาเข็มทุก 3 ม. โมดูลโครงสร้างใช้เหล็กดึงหนึ่งหน้าและกำลังวัสดุจากรายงานหน้า 3 พร้อมระบุ cover 40 mm และแบบรองรับง่ายเป็นสมมติฐาน ไม่ตีความแรงน้ำหนักตัวเองเป็นแรงออกแบบครบระบบ

### คำนวณจริงในแอป

- เรขาคณิตมาตราส่วนแกนเท่ากัน พื้นที่/ปริมาตรองค์ประกอบ พร้อมสูตรและการแทนค่า
- ผลคูณจากค่าตั้งต้น 41 สถานี × 13 องค์ประกอบ งานเผื่อความหนา 0.30 ม. งานปิดหัวท้ายที่อ่านจากแหล่งเดิม และการปัดลงแยกช่วง
- คอนกรีต BF1: พื้นที่เหล็ก ระยะลึกประสิทธิผล สมดุลแรงดึง–อัด กำลังดัด/เฉือน ความเครียด เหล็กขั้นต่ำ/ปลอก และแรงตัวอย่างน้ำหนักตัวเอง แรง Mu/Vu จริงเริ่มต้นเป็น null
- ดิน: ความเค้นประสิทธิผล กำลังเฉือน และลาดอนันต์แบบแห้ง/น้ำซึมขนานลาด; total stress ต้องระบุ Su ตัวอย่างนี้ไม่ใช่การวิเคราะห์เสถียรภาพรวม S6006 หรือน้ำลดฉับพลัน

### ผลและข้อมูลที่แยกไว้

ค่า Slope/W 3.378 (ตลิ่งเดิม), 2.588 (ตลิ่งพร้อมเขื่อน), 2.164 (น้ำลดฉับพลัน) เป็นผลที่รายงานเดิม ไม่ใช่ผลแอป และไม่อ้างรับรองรูปทรงที่ผู้ใช้แก้

ช่องว่างไม่กลายเป็นศูนย์: T25 ไม่มีผลคูณแต่ข้อมูลตั้งต้นครบ จึงคำนวณ 949.9875 ตร.ม. ได้ แผ่นใยรวมจึงเป็น 40,985 แทนค่าเดิม 40,035 ตร.ม. เมื่อปัดลงแยกช่วง ส่วนดินถมมีผลคูณที่คำนวณเพิ่มได้ 871.725 ลบ.ม. แต่พื้นที่ตั้งต้นยังขาด 2 ค่า (รวม AI128) ยอด 2,566 จึงเป็นยอดเฉพาะค่าที่ทราบ ไม่ใช่ยอดสมบูรณ์หรือการแก้ BOQ ที่อนุมัติ

Toe/sand/facing บางช่องตั้งต้นว่างแม้ผลเดิมบันทึกศูนย์ โมดูลจึงแสดงสถานะบางส่วน และไม่ใช้ค่าศูนย์นั้นยืนยันว่าไม่มีงานจริง รายการทรายหลังเขื่อนที่ตั้งต้นว่างทั้งหมดแสดงไม่ทราบ
