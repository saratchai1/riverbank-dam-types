# S6006 — ทะเบียนตรวจงานวิศวกรรม

Issue [#9](https://github.com/saratchai1/riverbank-dam-types/issues/9) เพิ่มหน้า **08 ตรวจงานวิศวกรรม** ต่อจากการเก็บทางเลือก A / B / C ใช้ข้อมูลโครงการและสมการ S6006-R2 เดิมเพื่อรวบรวมประเด็นที่ต้องตรวจตามสถานีและชุดข้อมูล

## ใช้หน้านี้ทำอะไร

หน้า 07 ใช้เปรียบเทียบตัวเลขระหว่างทางเลือก ส่วนหน้า 08 ใช้หาว่าเงื่อนไขใดยังต้องทบทวน ช่องใดยังไม่มีข้อมูล และควรกลับไปตรวจที่ข้อมูลชุดใด ทุกประเด็นมีสถานี ชื่อชุด รุ่นสถานการณ์ ค่า หน่วย สถานะ และเหตุผล

1. เลือก **08 ตรวจงานวิศวกรรม** ค่าเริ่มต้นแสดงสถานีที่เลือกอยู่ รวมค่าที่กำลังแก้และทางเลือกที่เก็บ
2. เลือกสถานีเดียวหรือทุกสถานี แล้วเลือกค่าปัจจุบัน ทางเลือกที่เก็บ หรือทั้งสองชนิด
3. กรองชุดที่มีประเด็นต้องทบทวน ข้อมูลขาด หรือชุดที่ยังตรงกับค่าต้นแบบ
4. เปิดรายละเอียดชุดที่ต้องการ ดูค่าที่คำนวณได้ เงื่อนไข ข้อมูลที่ขาด และเหตุผลประกอบ
5. การเปิดจุดแก้ของ **ค่าที่กำลังแก้** จะไปยังสถานีและช่องข้อมูลนั้น การเปิดจุดตรวจของ **ทางเลือกที่เก็บ** จะไปยังบัตรในหน้าเปรียบเทียบ หากต้องการแก้ชุดที่เก็บ ให้ใช้ปุ่ม **นำมาแก้ต่อ** ของบัตรนั้น
6. ส่งออก CSV หรือรายงานฉบับพิมพ์ของชุดที่แสดง การเลือกเฉพาะชุดที่มีประเด็นไม่ได้ตัดเงื่อนไขอื่นของชุดนั้นออกจากเอกสาร

หน้าจอและรายงานระบุจำนวนชุดก่อนกรอง จำนวนที่รวม และจำนวนที่ไม่ได้รวม ขอบเขตนี้ต้องอ่านพร้อมรายการคำนวณ ไม่ควรถือว่ารายงานที่กรองเหลือหนึ่งสถานีครอบคลุมทั้งโครงการ

## ความหมายของสถานะ

| สถานะ | ความหมาย |
| --- | --- |
| ต้องทบทวน | เงื่อนไขย่อยของโมดูลไม่เป็นไปตามเกณฑ์ หรือแรงที่กรอกเกินกำลังที่ใช้ตรวจได้ หรือ FS ต่ำกว่า 1 ในกลไกดินสมมติที่ระบุ |
| ข้อมูลยังไม่ครบ | ช่องที่เกี่ยวข้องยังเป็น `null` หรือไม่มีข้อความอ้างอิง ระบบคงช่องว่างไว้ |
| กำลังถูกระงับ | โมดูลยังไม่ให้ใช้ค่ากำลังนั้นตรวจแรง เนื่องจากเงื่อนไขที่ระบุ ไม่แทนด้วยศูนย์ |
| ผ่านเงื่อนไขย่อย | ผลของเงื่อนไขที่คำนวณในโมดูล เช่น Mu ไม่เกินกำลังดัดที่ใช้ได้ ยังต้องอ่านข้ออื่นและขอบเขตร่วมกัน |
| ผลแบบจำลองย่อย | มีผลคำนวณตามสมมติฐาน แต่ไม่ได้กำหนดเกณฑ์ยอมรับทั้งโครงการให้เอง |
| บันทึกข้อมูลแล้ว | มีค่าหรือข้อความอ้างอิงที่ผู้ใช้กรอก การมีข้อความไม่ได้ยืนยันว่าเอกสารหรือพารามิเตอร์นั้นผ่านการตรวจ |
| ไม่ใช้ในกรณีนี้ | เช่น Su ในโหมด effective stress หรือผล effective stress ในโหมด undrained |

**ค่าศูนย์ที่กรอกจริงต่างจากช่องว่าง:** Mu/Vu = 0 เป็นแรงที่ผู้ใช้ระบุ และ Su = 0 ในกรณี undrained ให้ FS = 0 ตามสมการ โดยยังคงขอบเขตและประเด็นที่ต้องตรวจ

### โครงสร้าง

ทะเบียนอ่านเงื่อนไขเหล็กคราก ความเครียดดึงขั้นต่ำ เหล็กดึงขั้นต่ำ เหล็กปลอกขั้นต่ำ ระยะปลอก ขีดจำกัดแรงเฉือน และการเทียบ Mu/Vu จากเครื่องคำนวณเดิม ตัวอย่างน้ำหนักตัวคานเป็นข้อมูลประกอบ ไม่ใช้แทนแรงออกแบบจริงที่ขาด

กำลังดัดที่ใช้ตรวจได้ต้องผ่านเงื่อนไข R2 เดิมก่อน ส่วนกำลังเฉือนอาจถูกจำกัดเหลือเพดานที่อิงคอนกรีตเมื่อรายละเอียดเหล็กปลอกไม่ครบ แม้ค่า Vu ต่ำกว่าจะอยู่ภายในเพดานนั้น ประเด็นรายละเอียดเหล็กปลอกยังคงแสดงแยกต่างหาก

### ดิน

ผลกรณีแห้ง น้ำซึมขนานลาด และ total stress จาก Su แสดงแยกกัน กรณีที่ไม่ใช้ในโหมดปัจจุบันไม่มีผลแทน และกรณี undrained ที่ยังไม่กรอก Su ไม่มี FS

FS < 1 ใช้ชี้ว่าแรงต้านเฉือนต่ำกว่าแรงเฉือนที่ต้องต้านในกลไกสมมติที่คำนวณ ค่า FS ที่มากกว่าหรือเท่ากับ 1 ยังคงเป็นผลแบบจำลองย่อย ไม่ได้หมายถึงผ่านเกณฑ์ออกแบบของโครงการ การเลือกเกณฑ์ต้องอิงชนิดโครงสร้าง กรณีวิเคราะห์ ความไม่แน่นอน และหลักเกณฑ์ของงาน

ระดับน้ำที่บันทึกเป็นบริบท ยังไม่ได้แปลงเป็นแรงดันน้ำรูพรุน การเปลี่ยนตัวเลขระดับน้ำไม่สร้างผลวิเคราะห์น้ำลดฉับพลันหรือเสถียรภาพรวมใหม่

## ค่าต้นแบบและ 41 สถานี

สถานีมาจากทะเบียน BOQ เดิม แต่ละสถานีที่ยังไม่มีข้อมูลเฉพาะเริ่มจากค่าต้นแบบเดียวกัน การแสดง 41 สถานีจึงไม่ได้แปลว่ามีข้อมูลสำรวจและแบบออกแบบที่ตรวจยืนยันแล้ว 41 ชุด

- **ค่าต้นแบบเดิม** หมายถึงทุกค่าตรงกับสถานการณ์ตั้งต้น รวมบริบท
- **มีข้อมูลเปลี่ยนจากต้นแบบ** หมายถึงมีอย่างน้อยหนึ่งค่าต่างออกไป การเพิ่มบันทึกเพียงช่องเดียวก็ทำให้ต่างจากต้นแบบได้
- ทางเลือกที่บันทึกไว้สามารถยังเป็นค่าต้นแบบได้
- ตัวเลขสรุปเป็นจำนวนสถานี/ชุด/ประเด็น ไม่ใช่เปอร์เซ็นต์ความสำเร็จหรือคะแนนความปลอดภัย

## รายงานและการส่งต่องาน

รายงานเก็บสำเนาโครงการ ตัวกรอง ขอบเขตสถานี รายการชุดข้อมูล และรุ่นข้อมูล ณ เวลาสร้าง การแก้ข้อมูลหรือสลับตัวกรองในแอปภายหลังไม่เปลี่ยนฉบับที่สร้างแล้ว หากสำเนาหาย เสียหาย หรือไม่ตรงกับข้อมูลที่ระบุ หน้ารายงานจะระงับการแสดงผลและการพิมพ์

รายงานนี้เป็นทะเบียนผลตรวจย่อยและประเด็นติดตาม หากต้องการสูตรและการแทนค่าครบของชุดหนึ่ง ให้เปิดชุดนั้นเป็นค่าที่กำลังแก้ แล้วใช้ **รายงานค่าปัจจุบัน** หากต้องการผลต่างระหว่างทางเลือก ให้ใช้ **รายงานเปรียบเทียบ**

ลิงก์สำเนารายงานใช้ข้อมูลในเบราว์เซอร์ที่สร้าง หากจะส่งให้ผู้อื่นให้บันทึก PDF การย้ายข้อมูลที่แก้ต่อได้ให้ใช้ **บันทึกโครงการ JSON** รูปแบบไฟล์โครงการ version 1 และ 2 และรายงานที่เคยสร้างยังใช้ได้ตามเดิม
