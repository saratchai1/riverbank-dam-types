# S6006 — เปรียบเทียบทางเลือกของสถานีเดียวกัน

Issue [#7](https://github.com/saratchai1/riverbank-dam-types/issues/7) เพิ่มการเก็บทางเลือก A / B / C ต่อจากโครงการรวม โดยคำนวณด้วยสมการ S6006-R2 ชุดเดิม ทุกค่าที่นำมาเทียบสร้างจากข้อมูลตั้งต้นใหม่ ไม่อ่านผลสำเร็จรูปจากไฟล์โครงการ

## วิธีใช้งาน

1. เปิด [โครงการ S6006](../projects/s6006/index.html) แล้วเลือกสถานีจาก BOQ
2. เปิด **07 เทียบทางเลือก** หรือปุ่ม **เปรียบเทียบทางเลือก** ใต้ข้อมูลโครงการ
3. ตั้งชื่อ เช่น `A · รูปตัดตั้งต้น` แล้วกด **เก็บค่าปัจจุบันเป็นทางเลือก** ระบบเก็บหน้าตัด คาน ดิน น้ำ และที่มาของค่าพร้อมกัน ทางเลือกแรกเป็นฐานเปรียบเทียบ
4. ใช้ **แก้หน้าตัด** หรือ **แก้คานและดิน** ปรับค่าที่ต้องการศึกษา แล้วกลับมาเก็บเป็น B หรือ C ได้สูงสุดสามทางเลือกต่อสถานี
5. ดูตารางเทียบทางเลือกที่เก็บกับ **ค่าที่กำลังแก้** เลือก **ใช้เป็นฐาน** หากต้องการเปลี่ยนชุดอ้างอิง การเลือกฐานไม่เปลี่ยนค่าที่กำลังแก้
6. ใช้ **นำมาแก้ต่อ** เพื่อคัดลอกทางเลือกนั้นกลับเข้าหน้าตัด คาน ดิน และบริบทของสถานี ทางเลือกที่เก็บยังคงเดิม
7. **บันทึกโครงการ JSON** เก็บทุกสถานีและทุกทางเลือกในไฟล์เดียว **เปิดโครงการ JSON** ใช้เปิดกลับหรือย้ายเครื่อง
8. ส่งออก **ตารางเปรียบเทียบ CSV** หรือ **รายงานเปรียบเทียบ** แล้วพิมพ์/บันทึกเป็น PDF

การนำทางเลือกออกมีขั้นยืนยันในบัตรทางเลือก หากนำชุดที่เป็นฐานออก ระบบเลือกทางเลือกที่ยังเหลือชุดแรกเป็นฐาน เมื่อไม่มีทางเลือกที่เก็บ ปุ่มรายงานและ CSV จะไม่เปิดใช้จนกว่าจะเก็บฐานใหม่ การนำออกไม่เปลี่ยนค่าที่กำลังแก้

## อ่านผลต่างอย่างไร

ตารางใช้ `Δ = ค่าของทางเลือก − ค่าของฐาน` ตัวเลขบวก/ลบไม่มีความหมายว่าแบบดีกว่าหรือแย่กว่าโดยตัวมันเอง ต้องอ่านร่วมกับค่าตั้งต้นและขอบเขตของผลนั้น

| ผลที่เทียบ | วิธีตีความ |
| --- | --- |
| หน้าตัด | แสดงความลาด ระยะราบ ความยาวลาด และความยาวขยายรูปตัดทฤษฎีตามที่กรอก |
| วัสดุ | แยกหินเรียง ชั้นทรายจำลอง ตีนหิน และแผ่นใย พร้อมค่าต่อความยาวและปริมาณตามความยาวที่กรอก ไม่มีการรวมต่างวัสดุเป็นยอดสุทธิหรือประเมินราคา |
| คาน | แสดง As, As,min กำลังดัด/เฉือนที่ใช้ตรวจได้ และ Mu/Vu ที่กรอก พร้อมอัตราส่วนแรงต่อกำลังตามเงื่อนไขของ R2 |
| ดิน | แยก FS แห้ง น้ำซึมขนานลาด และ total stress จาก Su ตามรหัสกรณีเดียวกัน ไม่จับคู่ค่าจากคนละกลไก |
| ค่าตั้งต้น | เปิดดูได้ทั้งรายการที่ต่างกันและค่าครบทุกทางเลือก รวมทั้งน้ำและแหล่งข้อมูล |

ผลต่างคำนวณเมื่อทั้งฐานและทางเลือกมีค่าตัวเลขที่ใช้เทียบกันได้เท่านั้น ช่องที่ไม่มีข้อมูลหรือกำลังที่ถูกระงับด้วยเงื่อนไขจะไม่ถูกแทนด้วยศูนย์ เปอร์เซ็นต์ผลต่างไม่แสดงเมื่อฐานเป็นศูนย์ อัตราส่วนแรงต่อกำลังจะไม่คำนวณผลต่างเมื่อแรงออกแบบของสองชุดต่างกัน

คานที่ไม่ผ่านเงื่อนไขเหล็กขั้นต่ำยังไม่มีกำลังดัดที่ใช้ตรวจ แม้ค่ากลศาสตร์ขั้นกลางจะเป็นบวก เมื่อแก้เหล็กจนกำลังใช้ตรวจได้ ตารางจะแสดงค่าที่คำนวณได้ แต่ไม่รายงานว่าเพิ่มขึ้นจากศูนย์ ส่วนสถานการณ์ undrained ที่ยังไม่มี Su เก็บไว้เป็นงานรอข้อมูลได้ โดยยังไม่มี FS

## ขอบเขตทางวิศวกรรม

- ชื่อสถานีระบุแถว BOQ ต้นฉบับ รูปตัดที่แก้ยังเป็นรูปทรงทฤษฎีจากแบบต้นแบบ ไม่ใช่ผลสำรวจจริงของแต่ละสถานี
- ความยาวขยายรูปตัดเป็นค่าที่ผู้ใช้กำหนด แยกจากความยาวรับผิดชอบของแถว BOQ หากเปลี่ยนความยาว ให้ใช้ค่าต่อความยาวประกอบการเทียบ ไม่ตีความยอดที่ลดลงว่าเป็นผลประหยัดจากหน้าตัดโดยอัตโนมัติ
- การเปลี่ยนรูปทรงหรือชั้นหินไม่สร้างแรงออกแบบคานใหม่ Mu/Vu ต้องมาจากแบบจำลองแรงที่เหมาะสมและแหล่งข้อมูลที่ระบุ
- ระดับน้ำในบริบทแสดงประกอบรูปตัดและรายงาน ไม่แปลงเป็นสนามแรงดันน้ำรูพรุนหรือผลวิเคราะห์น้ำลดฉับพลัน
- FS จากลาดอนันต์เป็นผลแบบจำลองย่อยตามสมมติฐานดินเนื้อเดียว ยังไม่ใช้รับรองเสถียรภาพรวม การทรุดตัว เสาเข็ม หรือการกัดเซาะ
- เงื่อนไขย่อยที่ผ่านยังมีขอบเขตตามโมดูล ไม่มีคะแนนรวม การเลือกผู้ชนะอัตโนมัติ หรือสถานะอนุมัติก่อสร้าง

สมการและเงื่อนไข R2 อยู่ใน [engineering.js](../projects/s6006/engineering.js) และรายการทบทวนเดิมใน [second-engineering-review.md](source-review/second-engineering-review.md)

## รายงานและการตรวจย้อน

รายงานเปรียบเทียบเก็บสำเนาข้อมูลของสถานี ทางเลือก ฐานเปรียบเทียบ และค่าที่กำลังแก้ ณ เวลากดสร้าง พร้อมรุ่นโครงการ รุ่นสถานการณ์ และเวลาประเทศไทย การแก้ค่าหรือเปลี่ยนฐานภายหลังไม่เปลี่ยนรายงานฉบับที่สร้างแล้ว

รายงานแสดงค่าตั้งต้นทุกชุดและส่งข้อความบริบทที่ยาวไปยังภาคผนวกโดยเก็บข้อความครบ ส่วน CSV มีรหัสสถานี รหัสทางเลือก รุ่นข้อมูล หน่วย สถานะ และเหตุผลประกอบแต่ละค่า

ลิงก์รายงานอ้างถึงสำเนาที่อยู่ในเบราว์เซอร์เครื่องที่สร้าง หากจะส่งให้ผู้อื่นให้บันทึก PDF หากจะย้ายงานให้ใช้ JSON เมื่อสำเนารายงานหาย เสียหาย หรือไม่ตรงรุ่น ปุ่มพิมพ์จะถูกระงับ ไม่มีการเปลี่ยนไปใช้ค่าเริ่มต้นโดยเงียบ ๆ

หากต้องการรายการคำนวณเต็มพร้อมสูตรและการแทนค่าของทางเลือกหนึ่ง ให้กด **นำมาแก้ต่อ** แล้วใช้ **รายงานค่าปัจจุบัน** ในแถบด้านบน

## รูปแบบไฟล์และความเข้ากันได้

โครงการใหม่ใช้ `riverbank.s6006.project` version 2 โดยเพิ่ม `stationComparisons` ซึ่งเก็บ `referenceId` และรายการ `{id, name, createdAt, scenario}` แยกตามรหัสสถานี ไม่เก็บผลคำนวณหรือเครื่องหมายอนุมัติเป็นค่าที่เชื่อถือได้

ไฟล์โครงการ version 1 ยังเปิดได้โดยคงข้อมูลและรหัสรุ่นเดิม เมื่อเก็บทางเลือกครั้งแรกจึงเพิ่มโครงสร้าง version 2 สำเนารายงานค่าปัจจุบันที่สร้างด้วย version 1 ยังตรวจรุ่นและเปิดได้ตามเดิม ไฟล์มิติ/คาน/ดินเก่าที่รองรับก่อนหน้านี้ยังผ่านเส้นทางนำเข้าเดิม

## การตรวจสอบ

- Unit tests ครอบคลุมทางเลือกแยกสถานี สำเนาที่ไม่เปลี่ยนตามต้นทาง ขอบเขตจำนวน/ชื่อ/รหัส การเลือกฐาน การนำมาแก้ต่อ การนำออก การเปิด JSON และความเข้ากันได้กับรายงาน version 1
- ทดสอบผลเปรียบเทียบกับตัวเลขจากเครื่องคำนวณเดิม โดยเฉพาะกำลังที่ใช้ไม่ได้ ค่าแรงที่ขาด ศูนย์ที่กรอกจริง Su ที่ยังไม่มี ชนิดดินต่างกัน และความยาวทฤษฎีที่เปลี่ยน
- Browser tests ใช้ข้อมูลทดสอบในบริบทแยก ตรวจขั้นตอน A/B/C → สลับสถานี → บันทึก/เปิดกลับ → CSV/PDF รวมทั้งหน้าจอ 390 px และพื้นที่พิมพ์ทุกหน้า

ชุดทดสอบเป็นหลักฐานพฤติกรรมของซอฟต์แวร์ในกรณีที่ทดสอบ การเลือกแบบจำลองและข้อมูลจริงให้ครบยังเป็นส่วนของการตรวจงานวิศวกรรม
