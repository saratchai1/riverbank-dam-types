## แยกข้อกำหนดเดิมออกจากหลักฐานวิดีโอ

บันทึกการคุยเดิมกล่าวถึง **ส.0005**, งานแบบมาตรฐานและรายการประกอบแบบ รวมถึงการทดลองกับแบบโครงการที่เสร็จแล้ว โครงการใหม่ และความถูกต้องที่ตรวจสอบย้อนกลับได้ของ **ปร.4** ข้อความเหล่านี้เป็นความต้องการจากงานเดิม ไม่ใช่สิ่งที่ยืนยันได้จากวิดีโอรอบนี้

ในเฟรมที่อ่านได้พบ **สธ.3173** และ **สธ.3201** ไม่พบ ส.0005 จึงไม่ถือว่าเลขแบบเหล่านี้เทียบเท่ากันหรือใช้แทนกันได้ การยืนยันฉบับแบบ รายละเอียด และเกณฑ์วิศวกรรมต้องอาศัยเอกสารต้นฉบับและผู้ตรวจงาน

ตารางใน B 00:40 แสดงเกณฑ์ FS กรณี 1 ≥1.30, กรณี 2 ≥1.50 และกรณี 3 ≥1.30 เอกสารนี้บันทึกว่าเป็น **ค่าที่หน้าจอต้นฉบับแสดง** เท่านั้น ไม่ใช้เป็นเกณฑ์รับรองของ workspace และไม่อ้างว่าตรงมาตรฐานใดโดยอัตโนมัติ

## เหตุผลที่ต่อยอด repository เดิม

`riverbank-dam-types` มีข้อมูลเดิมที่เกี่ยวข้องโดยตรง ได้แก่ แบบจำลอง 5 ชนิด T1-01…T5-01, Object Library 27 family, ข้อมูลพารามิเตอร์/ที่มาของค่า และรายการ BOQ ของแต่ละชนิดใน `data/site.json` พร้อมแบบจำลอง GLB ข้อมูลเดิมเองแยกค่าที่อ่านจากแบบกับค่าที่สมมติ และระบุว่ายังไม่ได้ตรวจเสถียรภาพ

จึงเพิ่ม workspace แยกจากหน้าดูแบบเดิม และใช้ประเภท/family เดิมเป็นบริบทในการทำงาน โดยคงแค็ตตาล็อก 5 ชนิด แบบจำลอง และ BOQ อ้างอิงไว้ งานที่เริ่มใน `floodwall` เป็นอีก branch หนึ่งและไม่ใช่แหล่งผลวิเคราะห์ยืนยัน ไม่ย้ายสูตร gravity-wall FS จากต้นแบบนั้นมาใช้กับลาดหินหรือระบบเสาเข็ม

### ความหมายของผลวิเคราะห์และปริมาณงาน

- **ไม่มีการคำนวณ FS ภายในรุ่นนี้** ผล FS ต้องมาจากเอกสารหรือระบบวิเคราะห์ภายนอกที่ผู้ใช้รับผิดชอบตรวจสอบแล้วนำเข้า พร้อมเอกสารอ้างอิง การใส่ reference ไม่ใช่การตรวจพิสูจน์ผลวิเคราะห์โดยโปรแกรม
- `current` หมายถึงผลถูกผูกกับ revision ปัจจุบัน ไม่ได้หมายถึง “ผ่าน” หรือ “รับรองแล้ว” หากหน้าตัด น้ำ หรือดินเปลี่ยน ผลเดิมต้องเป็น `stale`; การเลื่อนสถานีหรือแก้ราคาไม่ทำให้ผลวิศวกรรมเปลี่ยน revision การแทนที่แนวหรือชุดสำรวจจะเริ่มทะเบียนผลวิเคราะห์ใหม่พร้อมข้อความแจ้งและปุ่มย้อนกลับ ข้อมูลใน JSON เดิมยังเปิดคืนได้
- ตัวเลขเริ่มต้นเป็นข้อมูลสาธิต รูปตัดที่ปรับได้เป็นส่วนประกอบบางส่วนของ T1/T3 และไม่ใช่การรับรองความตรงแบบ ส.0005 หรือ สธ.3173/3201
- ปริมาณแนวคิดใน workspace แยกจาก BOQ อ้างอิงของแบบจำลองเดิม ไม่ประมาณเหล็กหรือดินขุดจากอัตราลอย ๆ และไม่แปลงราคาที่ไม่มีให้เป็นศูนย์บาท CSV ที่ส่งออกยังไม่ใช่ ปร.4 ฉบับสมบูรณ์ ปริมาณต่อเนื่องใช้พื้นที่หน้าตัด × ความยาวแนวศูนย์กลาง ยังไม่ได้หัก/เพิ่มรายละเอียดมุมต่อและระยะ offset ตามโค้ง

## ประเด็น UX ที่ต้องรักษาเมื่อพัฒนาต่อ

สถานี ขอบเขตข้อมูลสำรวจ และที่มาของค่าต้องเห็นได้ในจุดตัดสินใจ ผู้ใช้ต้องทราบเมื่ออยู่นอกช่วงสำรวจหรือยังไม่ได้เลือกหลุมเจาะที่ครอบคลุมสถานีนั้น ผลจาก revision เก่าต้องยังเห็นที่มาแต่ไม่ปะปนเป็นผลปัจจุบัน และคำว่า “เสร็จขั้นตอน” ต้องไม่ทำให้เข้าใจว่าแบบผ่านการตรวจวิศวกรรมแล้ว
