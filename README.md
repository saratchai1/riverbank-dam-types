## พื้นที่ออกแบบโครงการทั่วไป

เปิด **`studio.html`** หรือกด **ออกแบบโครงการ** ในหน้าเดิม เพื่อทำงานจากแนวสำรวจไปถึงหน้าตัดและปริมาณงาน แบบจำลองอ้างอิง 5 ชนิดและ Object Library เดิมยังอยู่ที่ `index.html` ตามเดิม

พื้นที่ออกแบบเพิ่มกระบวนการ 5 ขั้นตามวิดีโอที่ผู้ใช้ให้ โดยใช้ข้อมูลชุดเดียวกัน:

1. **สำรวจและแนวเขื่อน** — นำเข้าแนว CSV หรือ ASCII DXF เลือกเส้น/layer และยืนยันหน่วยเมตร; นำเข้ารูปตัด `station,offset,elevation`; เก็บระดับน้ำสูง ต่ำ ขณะสำรวจ และน้ำใต้ดินแยกกัน
2. **ข้อมูลดิน** — กรอกหรือนำเข้า CSV หลายหลุมเจาะ กำหนดช่วงสถานี ชั้นดิน γ/c′/φ′ แหล่งข้อมูล และสถานะยืนยันโดยผู้ใช้
3. **ออกแบบหน้าตัด** — ปรับหน้าตัดแนวคิด T3 เสาเข็มแนวหน้า + แผง + คาน + พื้น หรือ T1 หินเรียง + ชั้นกรอง + ตีนลาด + คาน BF; ดู 3D แปลน รูปตัด และรูปตามยาว
4. **ตรวจรูปตัดและผลวิเคราะห์** — เลือกสถานี และบันทึก FS จากรายงานภายนอกในกรณีก่อสร้าง น้ำต่ำ และน้ำลดเร็ว ผลถูกผูกกับ revision ของข้อมูลวิศวกรรม
5. **ปริมาณและส่งออก** — ตารางสูตร/สมมุติฐาน ค่าวัสดุและค่าแรงพร้อมแหล่งราคา; ส่งออก DXF/SVG รูปตัด, OBJ โมเดล, CSV ปริมาณ/สำรวจ/เสาเข็ม/ผลวิเคราะห์, JSON โครงการ และใบทบทวนผ่าน Print/PDF

เปิดตัวอย่างได้ทันที ไม่มี backend และไม่ต้องติดตั้ง dependency เพื่อใช้งาน ข้อมูลโครงการเก็บในเบราว์เซอร์ที่ใช้และสำรองด้วย **บันทึก JSON**; เมื่อจะเปิดเครื่องอื่น ให้นำ JSON ไปเปิดที่เครื่องนั้น

> **ขอบเขตแนวคิด:** หน้าตัดแก้ไขได้เป็นองค์ประกอบบางส่วนของแบบอ้างอิง ไม่ใช่การสร้าง GLB เดิมใหม่ครบทุกชิ้น ค่าเริ่มต้นของสำรวจ ดิน และมิติเป็นข้อมูลสาธิต ราคาเริ่มต้นเว้นว่าง หน้า Studio ทั่วไปยังไม่มี solver FS ไม่มีการเลือกแบบที่ผ่านโดยอัตโนมัติ และยังไม่ใช่แบบก่อสร้างหรือ ปร.4 ฉบับสมบูรณ์

### ไฟล์นำเข้า

ดาวน์โหลดไฟล์ตัวอย่างจากขั้นที่เกี่ยวข้องในหน้าเว็บได้ ตัวอย่างมีข้อมูลสมมติ ให้เปลี่ยนเป็นข้อมูลของโครงการก่อนใช้จริง

| ข้อมูล | คอลัมน์บังคับ | ความหมาย |
| --- | --- | --- |
| แนว CSV | `x,y` | พิกัดเมตร เรียงตามแนว; รองรับชื่อ `easting,northing` |
| รูปตัด CSV | `station,offset,elevation` | station เป็นเมตรหรือ `0+025`; offset ลบฝั่งน้ำ บวกฝั่งบก; elevation เป็นระดับสัมบูรณ์ใน datum เดียวกัน |
| ชั้นดิน CSV | `borehole,station,from_station,to_station,bottom,name,unit_weight,phi,cohesion,source` | หลายแถวต่อหลุม; bottom เรียงลดลงจากบนลงล่าง; γ เป็น kN/m³, φ เป็นองศา, c เป็น kPa |
| ผลวิเคราะห์ CSV | `station,case,fs,reference` | case = `construction`, `low-water`, `drawdown`; FS ค่าบวกจากรายงาน; ต้องมีหลักฐานอ้างอิง |
| โครงการ JSON | `schemaVersion: 1` | ใช้ไฟล์ที่บันทึกจาก workspace; ระบบตรวจโครงสร้างก่อนแทนที่ข้อมูลเดิม |

ตัวอ่าน DXF รับ `LINE`, `LWPOLYLINE` และ `POLYLINE` แบบเส้นตรงเปิดในระนาบ XY จากส่วน ENTITIES แสดงเส้นให้ผู้ใช้เลือก ไม่เลือกเส้นยาวที่สุดแทนผู้ใช้ เส้นโค้ง/bulge, เส้นปิด, block และ non-XY ไม่ถูกแปลงเงียบ ๆ; มีคำเตือนหรือปฏิเสธรายการนั้น ถ้า `$INSUNITS` ระบุหน่วยอื่นที่ไม่ใช่เมตร ต้องแปลงก่อนนำเข้า ยังไม่รับ DWG หรือ Binary DXF

นำเข้าแนวใหม่จะเริ่มรูปตัด ดิน และผลวิเคราะห์ใหม่สำหรับแนวนั้น; นำเข้ารูปตัดใหม่จะเริ่มทะเบียนผลวิเคราะห์ใหม่ มี **ย้อนกลับ** กู้การแก้ไขล่าสุดได้ 12 ครั้ง และควรบันทึก JSON ก่อนเปลี่ยนชุดข้อมูลสำคัญ ถ้าไฟล์ไม่ผ่าน validation ข้อมูลปัจจุบันไม่ถูกแทนที่

### ความหมายของผลและปริมาณ

- **ผลตรงรุ่นข้อมูล** หมายถึง revision ของแนว รูปตัด มิติ น้ำ และดินยังเหมือนตอนบันทึกผล ไม่ได้หมายความว่า FS ถูกต้องหรือแบบผ่านเกณฑ์ การแก้มิติ/น้ำ/ดินทำให้ผลเดิมล้าสมัย; การเปลี่ยนราคาหรือสถานีที่ดูไม่เปลี่ยน revision
- พื้นที่นอกรูปตัดสำรวจที่มีอยู่จะไม่มีผิวภูมิประเทศ ไม่เติม terrain ปลอมจากข้อมูลตัวอย่างหลังนำเข้าแนวจริง
- ปริมาณชิ้นส่วนต่อเนื่อง = **พื้นที่หน้าตัด × ความยาวแนวศูนย์กลาง** ใช้มิติชุดเดียวกับ SVG/DXF/3D แต่ยังไม่ถอดรายละเอียดระยะ offset ตามโค้ง มุมต่อ รอยต่อ หรือหักจุดซ้อนทับของชิ้นส่วน
- เสาเข็ม T3 มีหนึ่งแถวตามแนวหน้า นับ `floor(L/spacing)+1` เริ่มที่ STA 0 และมีเสาต้นปลายเมื่อช่วงระยะลงตัว ราคาต่อหน่วยเป็น **บาท/ต้นตามขนาดและความยาวที่แสดง** ไม่ใช่ราคาต่อเมตร
- ค่าวัสดุและค่าแรงที่ขาดเก็บเป็น `null` และแสดง `—`; ศูนย์บาทต้องกรอก `0` โดยตั้งใจ ยอดในหน้าราคาเป็นยอดเฉพาะรายการที่กรอกราคาครบ
- ไม่ได้ประมาณเหล็กด้วยอัตรา กก./ม³ หรือคำนวณขุด/ถมจากค่าคงที่ ยังไม่รวมรายการนอกองค์ประกอบแนวคิด ค่าใช้จ่ายอื่น Factor F หรือภาษี
- 3D แสดงเสาเข็มสูงสุด 800 ต้นพร้อมข้อความแจ้งการลดจำนวนที่วาด ขณะที่ตารางนับทั้งหมด; OBJ ปฏิเสธโมเดลที่เกิน 5,000 ต้น รูป 3D/OBJ จำกัดแนว 5,000 จุดและสำรวจ 20,000 จุดต่อช่วง; เกินนี้ยังใช้ข้อมูล 2D/ตารางได้

รายละเอียดเทียบต้นฉบับและงานที่ยังต้องพัฒนาอยู่ใน [docs/tutorial-review.md](docs/tutorial-review.md) ไม่รวม DWG, OCR/Excel ชั้นดิน, native GeoStudio, solver เสถียรภาพ, แบบหลายแผ่น, เหล็กเสริม และปริมาณครบงานในรุ่นนี้
