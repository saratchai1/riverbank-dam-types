# Riverbank Dam Types — เขื่อนป้องกันตลิ่งแบบมาตรฐาน 5 ชนิด

เว็บแอปดูแบบจำลอง 3D ของเขื่อนป้องกันตลิ่งแบบมาตรฐาน 5 ชนิด (T1-01 … T5-01) ยาวชนิดละ 100 ม.
คู่กับ Object Library 27 family และ BOQ ปร.4 ของแต่ละชนิด

> **ตัวอย่างสาธิต ห้ามใช้ก่อสร้าง** ขนาดชิ้นส่วนอ่านจากรูปขยายรูปตัดเขื่อนมาตรฐาน 1:50
> ค่าที่รูปไม่ได้ให้เป็นค่าสมมุติ (ติดป้าย "สมมุติ" ทุกตัว) รูปตัดสำรวจและความยาวเสาเข็มเป็นค่าสมมุติ และยังไม่ได้ตรวจเสถียรภาพ

| ชนิด | |
|---|---|
| T1-01 | เรียงหิน |
| T2-01 | เรียงกล่องเกเบี้ยน |
| T3-01 | ตอกเสาเข็ม |
| T4-01 | ตอกเสาเข็ม มีสายสมอ |
| T5-01 | ริมทะเล |

## ใช้งาน

- **แบบจำลอง**: เลือกชนิดเขื่อนทางซ้าย (หรือเปิดลิงก์ `#T2-01` ฯลฯ) หมุน ซูม คลิกชิ้นส่วนเพื่อดูรายการ ปร.4 ปริมาตร ช่วง STA ระดับ
  และคลาส IFC · ซ่อนหรือไฮไลต์ชิ้นส่วนจากรายการ · ตัดรูปตัดที่ STA ใดก็ได้ · คลิกบรรทัด BOQ เพื่อไฮไลต์ชิ้นที่ถูกนับ
- **Object Library**: 27 family ภาพตัวอย่าง 3D จากแบบจำลองชนิดที่ใช้ family นั้น พารามิเตอร์และที่มาของค่า
  (อ่านจากแบบ / รายการประกอบแบบ / สมมุติ) แยกตามชนิดและชิ้นที่ใช้ และ family ที่วางแผนไว้อีก 8 ตัว

## เปิดในเครื่อง

```bash
python3 -m http.server 8766
```

แล้วเปิด http://localhost:8766 (เปิดไฟล์ `index.html` ตรงๆ ไม่ได้ เพราะเบราว์เซอร์ไม่ให้โหลดข้อมูลจาก `file://`)

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `data/t1_01.glb` … `data/t5_01.glb` | แบบจำลอง glTF 2.0 ส่งออกจาก IngeTrazo 1 node ต่อชิ้น ข้อมูลชิ้นอยู่ใน node `extras` (ปริมาตร รายการ ปร.4 ช่วง STA พิกัด) |
| `data/site.json` | ชนิดเขื่อน (BOQ ปร.4 ที่มาของค่า) · แค็ตตาล็อก family · family ตามแผน |
| `assets/library/` | ภาพตัวอย่าง family ที่ถ่ายจาก IngeTrazo (family ที่ไม่มีภาพ หน้าเว็บสร้างภาพจากแบบจำลองเอง) |
| `vendor/three/` | three.js 0.186.0 (MIT License) |
